# VoxShop Telegram Bot

Полный Telegram-бот для покупки и продажи голды Standoff 2 / SO2 через ручные заявки.
Проект сделан **без папок**: все файлы лежат в корне архива.

## Что есть в этой версии

- Красивое главное меню VoxShop.
- Покупка голды через DonateAlerts или внутренний баланс.
- Если баланса не хватает — бот предлагает списать баланс и доплатить остаток через DonateAlerts.
- Продажа голды с ручной проверкой администратором.
- Пополнение баланса через DonateAlerts с ручным подтверждением в админке.
- Реферальная система: 10% бонусом от подтверждённых пополнений приглашённого клиента.
- Промокоды:
  - уникальные одноразовые, где админ указывает сумму, а бот генерирует случайный код;
  - обычные, где админ указывает код, сумму и количество активаций.
- Отзывы:
  - кнопка «Отзывы» в главном меню;
  - показ общего количества отзывов;
  - показ последних 5 отзывов;
  - отзыв можно оставить анонимно или с username;
  - отзыв ставится звёздочками;
  - сразу создаётся 637 стартовых отзывов.
- Нормальный профиль с балансом, статистикой сделок, реферальной ссылкой и кнопками.
- Админ-панель:
  - заявки;
  - пополнения баланса;
  - промокоды;
  - курсы и лимиты;
  - тексты и поддержка;
  - реквизиты;
  - клиенты;
  - рассылка;
  - статистика;
  - выдача админки.

## Основные реквизиты

По умолчанию используется DonateAlerts:

```text
DonateAlerts
Все карты + зарубежные платежи
https://www.donationalerts.com/r/kaktusik_crypa228
```

Ссылка не выводится огромным текстом в сообщении, а находится в кнопке:

```text
💳 Оплатить в DonateAlerts
```

## Установка

Нужен Python 3.11+.

```bash
pip install -r requirements.txt
```

## Настройка

`.env` не нужен. Всё находится в `config.py`.

Открой `config.py` и вставь токен:

```python
BOT_TOKEN = "PASTE_BOT_TOKEN_HERE"
```

Укажи админов:

```python
ADMIN_IDS = [7962973666]
```

Название магазина:

```python
BOT_NAME = "VoxShop"
```

Контакт поддержки:

```python
SUPPORT_CONTACT = "@kawalskuy"
```

## Запуск

```bash
python main.py
```

## Админ-панель

В Telegram напиши боту:

```text
/admin
```

Админка откроется только у тех, чей Telegram ID указан в `ADMIN_IDS` или кому выдали админку через панель.

## Как создать промокод

Открой:

```text
/admin → 🎁 Промокоды
```

Дальше выбери:

- `🎲 Уникальный одноразовый` — указываешь сумму, бот сам создаёт случайный код на 1 активацию.
- `✍️ Обычный промокод` — указываешь код, сумму и количество активаций.

Пользователь активирует код через:

```text
Профиль → 🎁 Активировать промокод
```

или кнопку `🎁 Промокод` в главном меню.

## Как работает баланс

Пользователь открывает:

```text
Профиль → 💰 Пополнить баланс
```

или кнопку `💰 Баланс` в главном меню.

После оплаты через DonateAlerts пользователь отправляет чек. Админ видит пополнение в:

```text
/admin → 💳 Пополнения
```

После подтверждения сумма зачисляется на баланс.

## Как работает покупка через баланс

При покупке бот смотрит баланс клиента:

- если денег хватает — можно оплатить полностью балансом;
- если денег не хватает — можно списать весь баланс и доплатить остаток через DonateAlerts;
- если баланс нулевой — бот сразу показывает оплату через DonateAlerts.

Если заявка отменена или отклонена, списанный баланс возвращается автоматически.

## Как работает реферальная система

В профиле пользователь видит свою реферальную ссылку.

Новый пользователь, который пришёл по ссылке, становится рефералом только если он ещё не был в боте.
Если человек уже запускал бота раньше, он не может стать чьим-то рефералом.

Когда реферал пополняет баланс и админ подтверждает пополнение, пригласивший получает 10% бонусом на баланс.

## Как оставить отзыв

Пользователь может открыть:

```text
Главное меню → ⭐ Отзывы → ⭐ Оставить отзыв
```

Также после завершения покупки или продажи бот отправляет кнопку для отзыва.
Отзыв можно оставить анонимно или с username.

## Важно

Бот не выполняет взлом, автоматический вход в аккаунты, обход защиты или любые небезопасные действия.
Все сделки подтверждаются вручную администратором.
Не просите у пользователей пароли, SMS-коды и данные входа.

## Новое в v6

### Управление отзывами
Админка → ⭐ Отзывы

Можно:
- добавить отзыв вручную;
- выбрать оценку звёздами;
- указать автора или сделать отзыв анонимным;
- открыть список последних отзывов;
- удалить любой отзыв.

Кнопка ⭐ Отзывы остаётся в главном меню для клиентов. Клиенты видят общее количество отзывов и последние 5.

### Отключение бота
Админка → 🤖 Бот

Можно:
- включить бота;
- отключить бота;
- указать причину отключения.

Когда бот отключён, обычные пользователи при /start и при нажатии кнопок увидят сообщение:

```text
VoxShop временно отключён
Причина: ...
```

Админы при этом могут пользоваться админ-панелью и включить бота обратно.
