# Telegram AI Girlfriend (Userbot)

ИИ-девушка для Telegram, которая работает через твой личный аккаунт. Заходит в аккаунт по номеру телефона, показывается "в сети", печатает и отвечает как настоящая девушка.

## Как это работает

- **Telethon** — вход в твой Telegram аккаунт (userbot)
- **OpenAI GPT** — генерация ответов от лица ИИ-девушки "Мия"
- Бот показывает статус "в сети" и имитирует набор текста
- Отвечает только на личные сообщения (настраивается)
- Можно ограничить список пользователей, которым бот отвечает

## Структура файлов

```
main.py          — точка входа, запуск бота
bot.py           — логика userbot (Telethon): онлайн, печатает, обработка сообщений
gpt.py           — интеграция с OpenAI GPT, история чатов
config.py        — конфигурация из .env
prompt.py        — системный промт (личность ИИ-девушки)
requirements.txt — зависимости Python
.env.example     — пример файла с настройками
```

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/qew-crypto/Mybots.git
cd Mybots
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Получить Telegram API ключи

1. Зайди на https://my.telegram.org/apps
2. Авторизуйся по номеру телефона
3. Создай приложение и скопируй **API_ID** и **API_HASH**

### 4. Получить OpenAI API ключ

1. Зайди на https://platform.openai.com/api-keys
2. Создай новый ключ и скопируй его

### 5. Настроить .env

```bash
cp .env.example .env
```

Заполни `.env` своими данными:

```env
API_ID=12345678
API_HASH=your_api_hash
PHONE=+79991234567
PASSWORD=your_2fa_password
OPENAI_API_KEY=sk-your-key
```

### 6. Запустить бота

```bash
python main.py
```

При первом запуске Telegram отправит код подтверждения — введи его в консоль.

## Команды

| Команда | Описание |
|---------|----------|
| `/clear` или `/сброс` | Очистить историю переписки с ИИ |

## Настройки

В файле `.env`:

- `OPENAI_MODEL` — модель GPT (по умолчанию `gpt-4o-mini`, можно `gpt-4o` или `gpt-4`)
- `ALLOWED_USERS` — список user_id через запятую (пусто = отвечать всем)

В файле `config.py`:

- `MAX_HISTORY` — сколько сообщений хранить в истории (по умолчанию 30)
- `MIN_TYPING_SECONDS` / `MAX_TYPING_SECONDS` — задержка "печатает..."
- `PRIVATE_ONLY` — отвечать только в личных сообщениях

## Кастомизация персонажа

Открой `prompt.py` и измени промт под себя:
- Имя, возраст, город
- Характер и интересы
- Стиль общения
- Ограничения

## Важно

- Используй **свой** Telegram аккаунт — бот войдёт в него
- Не злоупотребляй — Telegram может заблокировать аккаунт за спам
- OpenAI API платный — следи за расходами на https://platform.openai.com/usage
- Файл `.env` с ключами **никогда** не коммить в Git
