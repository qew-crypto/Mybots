# Standchillow Aimbot (Офлайн)

Android-приложение с оверлеем для игры Standchillow — **только для офлайн режима против ботов**.

## Возможности

- **Оверлей поверх игры** — плавающее окно с кнопками ON/OFF и закрытия, перетаскивается по экрану
- **Прицел (Crosshair)** — отображается в центре экрана поверх игры
- **Обнаружение врагов** — по цвету (красный, зелёный, жёлтый или пользовательский)
- **Автонаведение** — через AccessibilityService, симулирует свайпы для наведения на цель
- **Плавное наведение (Smooth Aim)** — настраиваемый коэффициент плавности
- **Режим хедшот** — автоматическое наведение на верхнюю часть цели
- **Триггер бот** — автоматический выстрел при наведении на цель
- **Настройки**: чувствительность, радиус FOV, цвет цели, коэффициент плавности

## Установка

1. Скачайте APK файл
2. Установите на Android устройство (Android 8.0+)
3. Разрешите установку из неизвестных источников

## Настройка

### Разрешения
При первом запуске нужно выдать два разрешения:
1. **Оверлей поверх окон** — для отображения прицела и панели управления
2. **Специальные возможности (Accessibility)** — для симуляции жестов наведения

### Параметры
- **Цвет цели** — выберите цвет, по которому будут обнаруживаться враги (зависит от игры)
- **Чувствительность** (0.1–5.0) — множитель скорости наведения
- **Радиус FOV** (50–500px) — область поиска врагов от центра экрана
- **Плавное наведение** — включить/выключить сглаживание движения
- **Коэффициент плавности** (0.05–1.0) — чем меньше, тем плавнее
- **Режим хедшот** — наведение на верхнюю часть цели
- **Триггер бот** — автоматический выстрел

## Как пользоваться

1. Откройте приложение и настройте параметры
2. Нажмите **ЗАПУСТИТЬ**
3. Разрешите захват экрана
4. Переключитесь в Standchillow
5. Плавающая панель позволяет включать/выключать аимбот
6. Для остановки нажмите ✕ на панели или вернитесь в приложение

## Сборка из исходников

### Требования
- Android SDK 34
- JDK 17
- Gradle 8.2+

### Команды
```bash
cd StandchillowAimbot
./gradlew assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`

## Структура проекта

```
app/src/main/java/com/standchillow/aimbot/
├── MainActivity.kt           # Главный экран настроек
├── AimbotPrefs.kt            # Хранение настроек (SharedPreferences)
├── AimbotEngine.kt           # Движок: обнаружение целей, расчёт наведения
├── ScreenCaptureService.kt   # Захват экрана через MediaProjection
├── OverlayService.kt         # Оверлей: прицел, панель управления
├── CrosshairView.kt          # Отрисовка прицела и маркера цели
└── AimAccessibilityService.kt # Симуляция жестов для наведения
```

## Дисклеймер

Это приложение предназначено **исключительно** для использования в офлайн режиме Standchillow против ботов. Разработчик игры разрешил создание модификаций для офлайн версии.
